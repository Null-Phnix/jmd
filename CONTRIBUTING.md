# Contributing to JMD

> *This is a personal project that happens to be open. I will merge PRs that make sense. I will close PRs that don't. No hard feelings.*

---

## What I Want

- **Bug fixes** — especially parser edge cases
- **New renderers** — DOCX, EPUB, PDF, whatever
- **Tests** — anything that increases coverage
- **Docs** — real examples, tutorials, not autogenerated API refs

## What I Don't Want

- Refactors that change code style for the sake of it
- Dependencies that pull in 50MB of transitive packages
- Breaking changes to the `.jmd` file format without discussion

---

## How to Contribute

1. Fork it
2. Branch: `git checkout -b feature/your-thing`
3. Write tests. Run them: `pytest tests/ -v`
4. Commit: `git commit -m "Add: your thing"`
5. PR with a description of what and why

---

## File Format Stability

The `.jmd` format is **pre-1.0**. I may change section syntax or annotation markup if the current form proves limiting. I will document any breaking changes in `ROADMAP.md`.

---

## Communication

- Issues: bug reports, feature requests, questions
- PRs: code only
- No Discord, no Slack. I check GitHub notifications.
